# Be the Threads – Threads and Cores Simulator

An interactive classroom simulation for BTIS3013 Operating System (Chapter 4: Threads).

A program adds up 40 numbers. Choose the number of **threads** and **cores**, then watch which threads run and which wait for a core. Turn the real-world costs (context switches and combining subtotals) on or off to see why **more threads are not always faster**.

## Run it
Open `index.html` in any modern browser. No installation or build step is needed.

## Try these
- 1 thread, 1 core
- 2 threads, 2 cores
- 4 threads, 2 cores
- 8 threads, 2 cores
- 4 threads, 4 cores
