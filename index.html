Be the Threads

A program has to add up 40 numbers. Split the work among threads, choose how many cores the computer has, and watch which threads run and which wait. More threads are not always faster.

Adding one number takes 1 s of CPU time. A thread can only work while it has a core. When there are more threads than cores, they take turns, 3 numbers at a time; switching a core to another thread (a context switch) costs 0.5 s. At the end, the main thread combines the subtotals, 1 s each.
